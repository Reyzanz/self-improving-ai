# Self-Improving AI Prototype

A browser-based prototype AI that can:

- analyze its own architecture and codebase
- search the web and research technology trends
- build a self-upgrade plan
- track memory and evolution over time
- propose next steps for continued autonomous development

This project is designed as a local web app that can be opened in a browser and used as a starting point for a stronger autonomous AI agent.

## Features

- Self-audit engine
- Tech stack discovery
- Internet research via public APIs
- Upgrade planner
- Memory and changes log in local browser storage
- Openable as a browser app with zero install

## Run

Open the project folder in a browser, or serve it locally:

```bash
cd self-improving-ai
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## What it demonstrates

This app simulates an AI that can:

1. inspect itself and describe the architecture it sees
2. search the web for relevant technologies
3. compare alternatives and propose improvements
4. store learning in a local memory
5. generate a roadmap for future growth

## Notes

This is a prototype and a concept app, not yet a full autonomous AGI system. It is meant to be an extensible foundation for a real self-improving agent.
